# 🛒 Superstore Retail Sales Analysis

## Project Overview
End-to-end data analysis project on Superstore retail dataset 
using Excel, SQL, and Power BI.

## Tools Used
- 📊 Microsoft Excel — Data Cleaning, Pivot Tables, Dashboard
- 🔵 MySQL — 15 SQL Queries (Basic to Intermediate)
- 🟡 Microsoft Power BI — 4 Interactive Dashboards, 51 Visuals

## Dataset
- Source: Kaggle — Sample Superstore Dataset
- Rows: 10,194 | Columns: 21
- Period: 2023–2024 | US Retail Sales

## Key Insights
- West region leads with $725K in total sales
- Tables sub-category has highest loss (-$17,753)
- High discounts (40%+) cause average loss of $105 per order
- Technology has highest profit margin at 12.5%

## Project Structure
- `samplesuperstore_data.xlsx` — Cleaned dataset with pivot tables
- `superstore_sql_analysis.sql` — All 15 SQL queries
- `Superstore_Dashboard.pbix` — Power BI dashboards
- `Superstore_Analysis_Report_RohanKumar.pptx` — Project report
